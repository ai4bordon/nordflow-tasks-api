NordFlow Tasks

Трекер проектов и задач: роли, Kanban-доска, комментарии, уведомления

Прототип: бэкенд + веб-интерфейс

Работает живьём: https://nordflow.veynx.xyz/ — это не макет и не скриншот: приложение поднято на своём сервере, с входом, базой и настоящими данными.

Это прототип, а не готовый продукт. Он показывает, что задача решена целиком: работает сервер, работает интерфейс. Осознанно не сделаны продакшн-деплой, интеграции с внешними сервисами и доработки «на будущее».

Веб-интерфейс

Пять экранов: дашборд с графиками, Kanban-доска с перетаскиванием карточек, список задач с фильтрами, команда с загрузкой и карточка задачи с историей изменений. Интерфейс отдаёт тот же сервер, что и API: отдельной сборки нет.

Что умеет

  • Три роли с разной видимостью данных: администратор, руководитель проекта, сотрудник
  • Права проверяются в каждом обработчике: сотрудник не видит чужие проекты и задачи
  • Смена статуса пишет историю и уведомляет ответственного
  • Поиск не спотыкается о «ё»: «верстк» находит «Вёрстка»
  • Сессия живёт в хранилище — после обновления страницы вход не теряется
  • Пароли хранятся как scrypt-хеш, а не в открытом виде

Как запустить

Нужен только Node.js 20+ — зависимостей нет, сборки нет.

node server.js — сервис поднимется и создаст демо-данные при первом запуске.

Откройте http://localhost:3000 — это и есть интерфейс со скриншотов выше.

node --test test/app.test.mjs — прогон тестов.

Демо-доступ: anna@nordflow.io (администратор), maxim@nordflow.io (руководитель), ilya@nordflow.io (сотрудник) — пароль выдаёт сервер в консоли при первом запуске, целиком — GET /api/demo
